# GeoGuessr Clone — 世界どこでしょう

ストリートビューだけを頼りに、世界のどこにいるかを地図上で当てるブラウザゲームです。
**ひとりで遊ぶ**ほか、**2〜4人でのオンライン対戦**にも対応しています。
インストール不要、Chrome / Edge / Safari / Firefox で動きます。

---

## 起動方法

### 方法 1：ダブルクリックで起動（おすすめ）
- **Mac** … `start.command` をダブルクリック
- **Windows** … `start.bat` をダブルクリック

ローカルサーバーが立ち上がり、自動でブラウザが開きます。終了はターミナル / コマンドプロンプトで `Control + C`。

> Mac で初回に「開発元が未確認」と出る場合は、`start.command` を右クリック →「開く」→「開く」を選択してください。
> Python 3 が入っていない場合は自動的に `index.html` を直接開く動作にフォールバックします
> （ひとり用は問題なく遊べますが、オンライン対戦は繋がらないことがあります）。

### 方法 2：手動でサーバーを立てる
```bash
cd "このフォルダ"
python3 -m http.server 8765
# → ブラウザで http://localhost:8765/ を開く
```

### 方法 3：ファイルを直接開く
`index.html` をダブルクリックしても遊べます。
ただし**オンライン対戦と API キーを使う場合は方法 1 か 2**（`http://localhost`）で開いてください。

# 1. ひとりで遊ぶ

1. ランダムな場所のストリートビューが表示されます。
2. 右下のミニマップにカーソルを合わせると拡大。地図をクリックしてピンを置きます。
3. **推測する**（または `Enter`）で確定。正解との距離に応じて **最大 5000 点**。
4. 設定したラウンド数を終えると合計スコアが出ます。ハイスコアはこの PC に保存されます。

### 設定項目
- **ラウンド数**：3 / 5 / 10
- **エリア**：世界・日本・アジア・ヨーロッパ・北米・南米・アフリカ・オセアニア
- **難易度**：やさしい（一目で国が分かる有名地）／ふつう（主要都市）／むずかしい（地方都市・手がかりが少ない場所）
- **制限時間**：1分 / 2分 / 5分 / 10分（既定は5分）
- **ルール**：移動・視点回転・ズームの可否（※ API キー使用時のみ）

# 2. オンライン対戦（2〜4人）

サーバーの用意は不要です。**WebRTC による P2P 通信**で、部屋コードを共有するだけで
インターネット越しに対戦できます。

### 準備：全員がこのゲームを開いている必要があります
このゲームは各自のブラウザ上で動くため、**参加者全員が自分の端末でゲームを開く**必要があります。
方法は次の 3 つです。

| 方法 | 手順 | 向いている場面 |
|---|---|---|
| **A. フォルダを共有** | Google Drive で共有 or ZIP を送る → 各自が `start.command`（Mac）/ `start.bat`（Windows）をダブルクリック | 少人数で手軽に。**全員に Python 3 が必要** |
| **B. URL を共有（おすすめ）** | このフォルダを静的ホスティング（GitHub Pages・Netlify・Cloudflare Pages など）に置き、URL を配る | **一番確実**。Python 不要、Windows / スマホでもそのまま遊べる |
| **C. ファイルを直接開く** | 共有したフォルダの `index.html` をダブルクリック | 手軽だが `file://` では **対戦が繋がらないことがある**ため非推奨 |

> **A を選ぶ場合の注意**
> - Google Drive 共有なら、相手側の同期が完了してから始めてください
> - Python 3 が無い Mac では、ターミナルで `xcode-select --install` を実行すると入ります
> - Windows は [python.org](https://www.python.org/downloads/) から Python 3 を入れてください
>
> **B が最も簡単です。** 中身は静的ファイルだけなので、フォルダをそのままアップロードすれば動きます。

### 遊び方
1. **ホスト役の人**：メニュー →「オンライン対戦」→ 名前を入力 →「**部屋を作る**」
2. 表示された **5 文字の部屋コード**（例：`K7QM3`）を仲間に伝える
3. **参加する人**：メニュー →「オンライン対戦」→ 名前を入力 → コードを入れて「**参加**」
4. 全員そろったら、ホストがモードなどを設定して「**ゲーム開始**」

### モード 1：全員が回答者
全員が同じ地点のストリートビューを見て、それぞれ地図にピンを置きます。
全員が回答するか制限時間が来たらラウンド終了。**全員のピンが色分けで一斉に公開**され、
距離と得点が表示されます。合計得点の一番高い人が勝ちです。

### モード 2：出題者あり
1 人が出題者になり、**世界地図をクリックして好きな場所を出題**します。
- 出題前にストリートビューのプレビューで確認できます（API キーがあれば存在チェックも自動）
- **出題者はそのラウンド得点なし**。出題役は**毎ラウンド全員に順番に回ります**
- ラウンド数は「人数 × 周回数」に自動設定され、全員が同じ回数だけ出題者になります
  （例：3 人 × 2 周 = 全 6 ラウンド）

### 誰が回答したかがすぐ分かる
プレイ中、画面右上の参加者一覧に**回答状況がその場で反映されます**。

- 見出しに **「回答 2 / 3」** と残り人数が出ます（全員そろうと「全員回答しました」）
- 回答した人の行は**緑に変わって ✓** が付きます
- まだの人は薄く表示され、**「···」が点滅**します
- 出題者ありモードでは、出題者は人数に含めません

誰を待っているのかがひと目で分かるので、粘るか先に押すかの判断がしやすくなります。

### 回答したら全画面で知らせる
誰かが回答すると、**「六根清浄」の演出が2秒間、全画面に出ます**。

| 時間 | 出るもの |
|---|---|
| 0〜1秒 | `rokkonshojo_1.png`（溶岩の「六根清浄」） |
| 1秒あたり | 2枚が重なって滑らかに入れ替わる |
| 1〜2秒 | `rokkonshojo_2.jpg`（黄緑の紋章） |

画像はゆっくり寄りながら切り替わります。
**画面は2秒で消えますが、音はそのまま裏で10秒流れ続けます。**

**この2秒のあいだ、そのラウンドの残り時間は止まります。**
演出で画面が隠れているあいだに持ち時間が減らないようにするためです。
止める長さは**親機が決めて全員に配る**ので、どの端末でも同じだけ止まります
（端末ごとに計算すると、演出の出方の違いがそのまま残り時間の差になるため）。

- 自分が回答したときは出ません（相手の回答だけ知らせます）
- **最後の1人の回答では出ません**。その回答でラウンドが終わり、すぐ結果画面に移るためです
- 同時に複数人が答えたら、順番に1人ずつ出します（止まる時間もその人数ぶん延びます）
- 画面に重なりますが**操作は妨げません**（地図もボタンもそのまま押せます）
- 効果音はメニュー画面の「効果音を鳴らす」で切れます（端末ごとに保存）
- 端末側で「視差効果を減らす」設定にしていると、穏やかな表示になります

画像が2枚とも読み込めたときだけ画像の演出になります。
置いていない・読めない場合は、金色の集中線が回る**文字だけの演出**に自動で切り替わります。

音は `rokkonshojo.mp3` を**先頭から10秒だけ**流し、最後の1.5秒でフェードアウトします。

音源（約430KB）は起動時には読まず、最初の画面タップのあとに裏で読み込みます。
読み込みが間に合わない場合や、ファイルが無い場合は、その場で合成した音で代用します
（読み込み待ちでゲームが止まらないようにするため）。

**スマートフォンで音が鳴らないとき**

- **iPhone は本体側面の消音スイッチ（マナーモード）がオンだと鳴りません。**
  これはブラウザ側から解除できない仕様です
- ブラウザは「一度も操作していないページ」で音を鳴らせません。
  画面を一度タップすれば以降は鳴ります
- 端末の音量も確認してください

### 早押しボーナス（任意）
ロビーの設定で、**回答が速かった順に加点**できます。**初期値は 0 で無効**なので、
使いたいときだけ数字を入れてください（1着 / 2着 / 3着、それぞれ 0〜2000）。

- 対象は**回答者だけ**です。出題者には付きません
- **その回で 1,000 点以上取った人だけ**が対象です。当てずっぽうで即答しても得しません
- 誰かが条件を満たさなかった場合、その枠は詰められて次の人が1着になります
- 順番はホストが受信した順で判定します。自己申告ではないので詐称できません
- 結果画面に「早押し+300」と内訳が出ます

なお**距離のスコアには手を加えていません**。速さは加点のみで、
正確さが主役という関係は変わりません。

### 途中で抜けてしまったら（再参加）
うっかりタブを閉じた、回線が切れた、間違えて退出した — そんなときは
**同じ部屋コードでもう一度参加するだけで、元の席に戻れます。**

- **得点はそのまま引き継がれます**（席の色・並び順も変わりません）
- 抜ける前にそのラウンドの回答を済ませていれば、**その回答も有効なまま**です
  （戻ってから答え直す必要はありません）
- 出題者が抜けて戻った場合も、出題者のまま（得点なし）で続行します
- 抜けている間、他の人はその人を待たずに進行します

同じブラウザから戻る場合は自動的に本人と判定されます。別の端末やブラウザから戻る場合は、
**抜けたときと同じ名前**を入力してください。

### 対戦時の注意
- ホストが退出するとゲームは終了します
- ゲーム開始後、**一度も参加していない人の新規参加はできません**（再参加は上記のとおり可能）
- 誰かの回線が切れると、その人を除いて進行が続きます
- 残り時間は全員に同じ値が表示されます（端末ごとの時計のズレの影響を受けません）
- 厳しいファイアウォールや一部の企業ネットワークでは P2P 接続できないことがあります
- 出題地点の座標は各プレイヤーの端末に送られるため、開発者ツールを開けば技術的には
  座標を覗けます。仲間内で遊ぶ前提の作りです

## 操作

| キー / 操作 | 内容 |
|---|---|
| 地図をクリック | ピンを置く |
| 地図にカーソルを乗せる | 地図が拡大表示される（スマホは「🗺 地図」をタップ） |
| 地図の上でホイール | 地図をズーム（拡大・縮小） |
| **＋ / − ボタン** | **地図パネル自体の大きさを4段階で変更**（設定は次回も保持） |
| 📌 ボタン | 拡大したまま固定する |
| `Esc` | 地図の固定を解除 |
| `Enter` | 推測を確定 / 次のラウンドへ（ソロ） |
| **⟲ ボタン（右上）** | **最初の地点・最初の向きに戻る**（ソロ・対戦とも、API キー不要） |
| **⏭ ボタン（右上）** | **この場所をスキップして別の場所にする**（対戦は多数決） |
| **✕ ボタン（右上）** | **どの画面からでもゲームを抜ける**（確認ダイアログあり） |

### スマートフォンで遊ぶ
画面幅に合わせてレイアウトが切り替わります。パソコンとは操作が少し変わります。

- **操作ボタンは画面下**（親指で届く位置）に並びます
- **地図は普段たたまれていて、右下の「🗺 地図」をタップすると画面の下半分に大きく開きます**
  （タッチ端末はカーソルを乗せられないため。閉じるときは地図右上の 📌）
- ノッチやホームバーを避けて配置されます
- ツールチップは表示しません（タップで出っぱなしになるため）

対戦もそのまま遊べます。パソコンとスマホが混ざっていても問題ありません。

### 地図の大きさ
回答用の地図は、カーソルを乗せると拡大表示されます。その拡大サイズは地図の右上にある
**＋ / −** ボタンで4段階に変えられます。選んだ大きさはブラウザに保存され、次回も同じ大きさで開きます。
地図の中身のズーム（縮尺）は、ホイールか地図左上の **＋ / −** で操作できます。

### 地名が見えてしまうときは
埋め込みモード（API キー無し）では、ストリートビューの左上に Google が地名を表示します。
これは Google 提供の UI で消せないため、**画面上端を切り落として隠しています**。

もし環境によって隠れきらない場合は、`css/style.css` の先頭にある値を大きくしてください。

```css
--sv-crop:96px;    /* この値を 120px などに増やす */
```

（下端の Google ロゴは利用規約上、隠さずに残しています）

### 遊べない場所に当たったら（スキップ）
建物の中に入ってしまった、画像が出ない、動けない — そんなときは画面右上の **⏭** で
その場所をやめて別の場所に差し替えられます。**ラウンド数は減りません**し、
制限時間も引き直されます。一度出た場所は二度と出題されません。

- **ソロ** … 押すとすぐ別の場所に変わります
- **対戦（全員回答）** … **回答者の過半数**が押すと変わります。押した人数は全員に見え、
  もう一度押せば取り消せます（2人なら2人、3〜4人なら2人で成立）
- **対戦（出題者あり）** … 回答者の過半数で出題フェーズに戻ります。
  出題者自身は単独で「出題し直す」ことができます

### 迷子になったら
歩き回って元の場所が分からなくなったら、画面右上の **⟲** を押すと
**最初に表示された地点・向きにそのまま戻ります**。何度押しても同じ場所に戻るので、
探索して行き詰まったらいつでもやり直せます。ソロでも対戦でも使えます。

### 途中でやめる
画面右上の **✕** はどの画面からでも押せます。押すと確認ダイアログが出て、
状況に応じた注意が表示されます。

- ソロ … 中断してメニューに戻る（スコアは記録されません）
- 対戦・ホスト … **抜けると参加者全員のゲームが終了する**旨を警告
- 対戦・参加者 … 同じ部屋コードで戻れば復帰できる旨を案内

### 設定手順
1. [Google Cloud Console](https://console.cloud.google.com/) でプロジェクトを作成
2. **Maps JavaScript API** を有効化
3. 「認証情報」から API キーを作成
4. ゲームのメニュー画面 →「Google Maps API キー設定」に貼り付けて **保存**

キーはブラウザの `localStorage` にのみ保存され、外部には送信されません。
キーが無効な場合は自動的に埋め込みモードへ切り替わります。

> 無料枠を超えると課金される可能性があります。キーには必ず **HTTP リファラー制限**を
> 設定してください。GitHub Pages で公開している場合は、次の 2 つを許可リストに入れます：
>
> ```
> http://localhost:*/*
> https://naaktslaktauge.github.io/geoguessr/*
> ```
>
> なお API キーはブラウザの JavaScript から使う性質上、開発者ツールを開けば見えてしまいます。
> **公開ページで使うキーには必ずリファラー制限と使用量上限を設定してください。**

## スコア計算

本家と同じ指数減衰式を採用しています。

```
スコア = 5000 × exp(−10 × 距離km ÷ 地図の広さkm)
```

「地図の広さ」はエリアごとに変わり（世界 = 14,916 km、日本 = 2,200 km など）、
狭いエリアほど正確さが要求されます。出題者ありモードは常に「世界」基準です。

## 収録地点

**20,378 か所・106 の国と地域**（`js/locations.js`）。

| エリア | 計 | やさしい | ふつう | むずかしい |
|---|---|---|---|---|
| 日本 | 1,782 | 214 | 588 | 980 |
| アジア | 3,656 | 439 | 1,206 | 2,011 |
| ヨーロッパ | 6,366 | 764 | 2,101 | 3,501 |
| 北米 | 3,650 | 439 | 1,203 | 2,008 |
| 南米 | 2,042 | 245 | 674 | 1,123 |
| アフリカ | 1,442 | 173 | 476 | 793 |
| オセアニア | 1,440 | 173 | 475 | 792 |
| **合計** | **20,378** | | | |

どのエリアと難易度の組み合わせでも 10 件以上あるので、選んだ条件がそのまま反映されます。

### 難易度の決め方
このゲームで点が入るかどうかは、ほぼ **「国を当てられるか」** で決まります。
世界モードなら、国さえ合っていれば 4,500 点前後は取れるからです。
そこで難易度は「国の見分けやすさ」を主、「その街の知名度」を従として点数化しています。

| 要素 | 配点 |
|---|---|
| 国の見分けやすさ（文字・景観・車・植生、日本人にとってのなじみ） | 0 / 1.5 / 3.0 |
| 国際的な知名度（GeoNames の別名の数＝何言語で呼ばれているか） | 0 〜 2.0 |
| 日本語の呼び名がある | +0.5 |
| 首都 | +0.5 |
| 人口 | 0 〜 0.5 |
| 名所としての象徴性（人手で選んだ344件のみ） | +0.3 〜 2.0 |

**点数はエリアの中での相対順位に直してから** 上位12%＝やさしい、45%まで＝ふつう、
残り＝むずかしい に割り当てます。こうしないと日本を選ぶと全部やさしくなり、
アフリカを選ぶと全部むずかしくなってしまいます。
「日本の中では難しい町」「アフリカの中では分かりやすい街」を表せるようにするためです。

つまり **やさしい = 見覚えがある、ではなく「点が取りやすい」** という意味です。
知らないドイツの町でも、ドイツと分かれば高得点なので「やさしい」に入ります。

以前は人口と首都かどうかで決めていましたが、メキシコ市郊外の Ecatepec（160万人・無名）が
「やさしい」になるなど噛み合っていなかったため作り直しました。

### データの中身
**名所・ランドマーク 344 か所**は 1 地点ずつ人手で選び、座標は**最寄りの車道上へ吸着**
させてあります（名所ちょうどの座標は建物の中に落ちて動けなくなるため。移動量の中央値 22m）。
独立した 2 つの地理サービスで突き合わせ、食い違う地点も修正しています。

**街 約 20,000 か所**は GeoNames の都市データ（人口 500 人以上・全世界 235,674 件）から
機械的に選んでいます。国ごとに知名度の高い順に取ることで偏りを抑え、
既存地点の 3km 以内は除いています。街の中心座標をそのまま使っているため、
まれに始点が不便なことがあります（その場合は **⏭ スキップ** をどうぞ）。

日本・韓国・台湾・香港は漢字表記、その他は片仮名の音訳を使います。
日本語名が存在しない小さな街は現地表記のままです。

### データ形式
1 万件あるため、ファイルでは配列で持ち、読み込み時にオブジェクトへ展開しています
（そのままの書式だと 1.5MB を超えるところ、830KB に収まっています。

## ファイル構成

```
GeoGuessr/
├── index.html          画面の構造（メニュー / ソロ / 対戦）
├── start.command       起動スクリプト（macOS）
├── start.bat           起動スクリプト（Windows）
├── rokkonshojo.mp3     回答アナウンスの効果音
├── rokkonshojo_1.png   演出の前半（0〜5秒）に出る画像
├── rokkonshojo_2.jpg   演出の後半（5〜10秒）に出る画像
├── css/style.css       スタイル
├── test/               自動テスト（run-tests.command をダブルクリック）
└── js/
    ├── common.js       共通処理・スコア計算・対戦の純粋ロジック
    ├── locations.js    出題地点データ（120か所）
    ├── maps.js         Leaflet 地図・距離計算
    ├── pano.js         ストリートビュー表示（2モード）
    ├── fx.js           回答アナウンスの演出と効果音
    ├── net.js          P2P 通信（PeerJS / WebRTC）
    ├── multi.js        オンライン対戦の進行
    └── game.js         ソロプレイの進行
```

ロジックの自動テストを同梱しています。`test/run-tests.command` をダブルクリックすると、
ブラウザ無しで対戦の進行（出題者の交代・採点・切断処理など）を検証できます。
地点データを編集したあとの確認にも使えます。

対戦は**ホストが進行の正**となる星形トポロジで、ゲストはホストとだけ通信します。
ホストが状態をまとめて配信し、全員が同じ状態を描画する仕組みです。

## 必要環境
- インターネット接続（ストリートビュー・地図タイル・P2P 接続に必要）
- モダンブラウザ（Chrome / Edge / Safari / Firefox）。スマートフォンでも遊べます
- `start.command` / `start.bat` を使う場合は Python 3
  （Mac は `xcode-select --install`、Windows は python.org から導入。
  　無い場合はブラウザで直接開く動作に自動で切り替わります）

外部ライブラリは Leaflet と PeerJS を CDN から読み込みます。
地図タイルは OpenStreetMap / CARTO、ストリートビューは Google の提供です。
本作は個人利用・学習目的の非公式クローンで、GeoGuessr AB とは関係ありません。
